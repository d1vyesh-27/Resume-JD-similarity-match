# Data Directory

This directory is intended for local datasets and experiments. 

**Raw and large datasets should NOT be committed to GitHub.**

## Usage
You can place local test resumes, downloaded job postings, or sample datasets (e.g., from Kaggle) here.

## Data Sources to Consider
- Kaggle Resume Dataset
- Public job-posting datasets

## Important Note
Be mindful of licensing and data-use restrictions for any public datasets. Make sure to use `.gitignore` to avoid accidentally committing private resumes or proprietary job application documents.
